# Hajdú Réka — Frontend Developer Portfolio

Personal portfolio built with Vue 3 and Vite, featuring a dark terminal/IDE aesthetic, bilingual support (EN/HU), and scroll-driven animations.

🔗 **Live:** [hajdureka.hu](https://hajdureka.hu)

---

## Tech Stack

- **Vue 3** — Composition API, `<script setup>`
- **Vite** — build tool
- **Tailwind CSS** — utility classes
- **JavaScript**
- Custom `useLang.js` composable for EN/HU language switching

---

## Features

- 🌐 Bilingual (English / Hungarian) with persistent language preference via `localStorage`
- 🖥️ Terminal-inspired design with typewriter role animation and preloader boot sequence
- ♿ WCAG 2.1 AA accessibility compliant
- 📜 Scroll-driven animations using Intersection Observer
- 🖱️ Cursor trail effect
- 🎨 Active nav highlight on scroll
- 📱 Fully responsive with mobile hamburger menu

---

## Sections

- **Hero** — code object intro with cycling typewriter animation
- **About** — bio and info cards
- **Projects** — F1 Track Weather App, Linktree Clone, Minesweeper
- **Skills** — animated progress bars with scroll reveal
- **Experience** — git log style timeline
- **Contact** — email and social links
